# Optional but strongly recommended: the anchored thinning and the watershed
# flood are JIT-compiled.  Without numba they fall back to plain Python and
# become very slow on real-size rasters.
# Numba 0.61.x covers Python 3.10-3.13 on Linux/macOS/Windows x86_64 and
# macOS ARM.  Python 3.14 and Windows ARM64 need the 0.68 branch, which has
# wheels for those targets.  Numba 0.68 has no Intel-macOS wheel, so on that
# combination it is omitted and the engine uses its slow pure-Python fallback.
#
# PEP 508 markers have no parentheses, so the conditions are distributed.
# 3.10-3.13 everywhere except native Windows ARM64:
numba>=0.59,<0.62; python_version < "3.14" and sys_platform != "win32"
numba>=0.59,<0.62; python_version < "3.14" and platform_machine != "ARM64"
# 3.14 everywhere except Intel macOS:
numba>=0.68,<0.69; python_version >= "3.14" and sys_platform != "darwin"
numba>=0.68,<0.69; python_version >= "3.14" and platform_machine != "x86_64"
# Windows ARM64 on 3.12/3.13:
numba>=0.68,<0.69; python_version < "3.14" and sys_platform == "win32" and platform_machine == "ARM64"
